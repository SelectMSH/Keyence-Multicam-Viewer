The Purspose of this program is to display a grid layout on a monitor and in each grid square display the last taken image with tools of a IV4 Keyence Camera. This program will allow 1 - 9 cameras to be displayed on the screen.

How to use:

1) Enable Keyence Webmonitor feature of each Camera found in the following menu.

Sensor Advance > Utility > Communication Settings > Webmonitor

enable HTTP and reboot the sensor.

2) To verify that the web monitor is reachable you can open a brower and navigate to the address of the camera. Replace the following IP address with IP of your camera.

"http://192.168.0.1/iv4-wm.html"

3) When lauching the program you can click "Config" and it will open a window that allows you to setup how many cameras to connect to, what ip addresses, and their names to display on the window layout. After saving the program will adjust the window count/window names. These settings will persist until they are modified
